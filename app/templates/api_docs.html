Developer API Documentation

RESTful HTTP API endpoints for programmatic machine learning inference, telemetry retrieval, and system monitoring.

GET /api/v1/health

Checks server liveness, database connectivity, and lists all initialized ML models.

Example Request (cURL):
curl -X GET http://127.0.0.1:5000/api/v1/health
Sample Response (200 OK):
{
  "status": "healthy",
  "database": "connected",
  "models_loaded": ["yield", "disease", "fertilizer"],
  "timestamp": "2026-09-05T05:35:10.123456"
}
POST /api/v1/predict/yield

Submits agronomic, soil, and climate parameters to predict expected crop yield in kg/hectare alongside an estimator variance confidence interval.

Example Request (cURL):
curl -X POST http://127.0.0.1:5000/api/v1/predict/yield \ -H "Content-Type: application/json" \ -d '{ "crop_type": "wheat", "soil_ph": 6.5, "rainfall_mm": 650.0, "temperature_c": 21.5, "humidity_pct": 60.0, "nitrogen": 120.0, "phosphorus": 45.0, "potassium": 40.0 }'
Sample Response (200 OK):
{
  "status": "success",
  "prediction_type": "yield",
  "crop_type": "wheat",
  "predicted_yield_kg_per_hectare": 4215.35,
  "confidence_pct": 92.4,
  "confidence_interval": [3840.10, 4590.60],
  "std_deviation": 191.45,
  "unit": "kg/ha",
  "log_id": 14
}
POST /api/v1/predict/disease

Diagnoses foliar pathogen vulnerability levels (low, medium, high) based on microclimate variables, sustained leaf wetness hours, and past field infection history.

Example Request (cURL):
curl -X POST http://127.0.0.1:5000/api/v1/predict/disease \ -H "Content-Type: application/json" \ -d '{ "crop_type": "rice", "temperature_c": 28.5, "humidity_pct": 89.0, "rainfall_mm": 210.0, "leaf_wetness_hours": 12.0, "prior_disease_history": 1 }'
Sample Response (200 OK):
{
  "status": "success",
  "prediction_type": "disease",
  "crop_type": "rice",
  "risk_level": "high",
  "confidence_pct": 87.5,
  "class_probabilities": {
    "low": 2.5,
    "medium": 10.0,
    "high": 87.5
  },
  "advisory": "CRITICAL ALERT: Environmental conditions strongly favor outbreak. Immediate fungicide application recommended.",
  "log_id": 15
}
POST /api/v1/predict/fertilizer

Recommends an optimal fertilizer treatment formulation (Urea, DAP, MOP, NPK blend, or Compost) tailored to soil test values and crop type.

Example Request (cURL):
curl -X POST http://127.0.0.1:5000/api/v1/predict/fertilizer \ -H "Content-Type: application/json" \ -d '{ "crop_type": "maize", "soil_ph": 6.5, "nitrogen": 25.0, "phosphorus": 45.0, "potassium": 50.0, "moisture_pct": 55.0 }'
Sample Response (200 OK):
{
  "status": "success",
  "prediction_type": "fertilizer",
  "crop_type": "maize",
  "recommended_fertilizer": "Urea",
  "confidence_pct": 94.2,
  "class_probabilities": {
    "Compost": 1.2,
    "DAP": 0.5,
    "MOP": 0.8,
    "NPK": 3.3,
    "Urea": 94.2
  },
  "fertilizer_info": "High Nitrogen (46-0-0) source for vegetative growth and chlorophyll synthesis.",
  "log_id": 16
}
GET /api/v1/history?limit=20

Retrieves chronological list of logged inference transactions and input snapshots stored in the SQLite database.

Example Request (cURL):
curl -X GET "http://127.0.0.1:5000/api/v1/history?limit=5"
